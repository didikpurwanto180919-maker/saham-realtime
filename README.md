# Saham Real-Time IDX Dashboard AI

Dashboard analisis teknikal dan prediksi harga saham berbasis *Machine Learning* (Random Forest) untuk instrumen pasar modal Bursa Efek Indonesia (IDX) secara *real-time*.

## Fitur Utama
- **Real-Time Data Feeds:** Terintegrasi langsung dengan Yahoo Finance API (`yfinance`).
- **Feature Engineering Lengkap:** Perhitungan indikator teknikal lanjutan seperti RSI, MACD, Bollinger Bands, dan ATR (*Average True Range*).
- **Manajemen Risiko Otomatis:** Perhitungan *Stop Loss* dan *Take Profit* dinamis berbasis tingkat volatilitas pasar harian.
- **Auto-Refresh & Alarm Sound:** Halaman memperbarui data secara otomatis setiap 5 detik dengan efek notifikasi suara.
